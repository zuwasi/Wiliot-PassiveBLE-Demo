Step 2: The Paper

PassiveBLE: Fully Commodity-Compatible BLE Backscatter

Dong et al. · ACM MobiCom 2025 · arXiv 2503.11490

What They Did

First BLE backscatter system that establishes real BLE connections on data channels — not just advertising packets. Works with unmodified smartphones.

Key Innovation

Distributed coding scheme offloads channel encoding to the excitation source via XOR operations on RF signals — tags stay ultra-low-power.

Three Technical Breakthroughs

Synchronization

Coherent-detection circuit wakes tags with 93 ns accuracy and -30 dBm sensitivity.

Distributed Coding

XOR on RF signals: excitation source handles dynamic parameters, tags just scatter. 9.9 µW.

Connection Scheduler

Real BLE connections — establishment, maintenance, frequency hopping — for multiple tags.

MATHEMATICA SIMULATION

RF Link Budget

Free-space path loss at 2.44 GHz — logarithmic increase, 17m paper max marked
Received power at 5 TX levels (0-20 dBm), -30 dBm wake-up threshold
Insight: Friis equation models RF propagation. At 20 dBm EIRP, the signal stays above the -30 dBm wake-up threshold to ~3m. Lower TX powers fall below threshold almost immediately — excitation source proximity is critical for passive operation.
MATHEMATICA SIMULATION

Wake-Up Performance

Logistic model (blue) vs paper data (red dots), -30 dBm / 91% threshold
Success rate vs distance — >95% within 1.5m, >80% within 2.5m
Insight: The logistic model closely fits the paper's measured wake-up curve. Steep transition around -30 dBm — below -32 dBm, wake-up drops to near zero. This defines practical excitation source placement: keep within 2m for reliable operation.
MATHEMATICA SIMULATION

Throughput Analysis

LoS goodput: LE 2M peaks at 974 kbps (blue), LE 1M at 532 kbps (red)
LoS vs NLoS comparison — NLoS reduces throughput by 15-30%
Insight: Goodput decays exponentially with distance. LE 2M maintains ~500 kbps at 5m but drops to ~150 kbps at 15m. NLoS (dashed) shows significant degradation from walls/obstacles. For dock-door use, tags stay within 2m so throughput remains near peak.
MATHEMATICA SIMULATION

BER & Connection Performance

BER vs distance (log scale) — LE 2M higher BER but still superior throughput
Establishment (green) vs maintenance (orange) — 99.9% reference line
Insight: BER grows from 10-6 at close range to 10-4 at 18m. LE 2M has higher BER due to faster symbol rate but still delivers superior net throughput. Connection maintenance degrades faster than establishment — sustained transmission exposes tags to more channel variability.

TECHNICAL COMPARISON

When to Use Which

Mathematica

  • R&D exploration — modify equations on the fly
  • Symbolic derivation — CAS for closed-form solutions
  • Live demos — Manipulate for instant parameter sweeps
  • Publication figures — vector, camera-ready
  • Rapid prototyping — fewer lines for complex math

Python + Streamlit

  • Sharing with engineers — browser, no license
  • CI/CD integration — pytest, GitHub Actions
  • Web dashboards — Plotly interactivity, tooltips
  • ML/data pipelines — pandas, scikit-learn, TF
  • 3D exploration — rotatable, zoomable surfaces
Use Mathematica to explore and discover. Use Python to ship and scale.
